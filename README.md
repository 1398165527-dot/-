# 学习力工作台（验证版）

面向学习力老师（学习咨询 / 陪跑 / 小班课）的个人业务工作台。本仓库为**前端单机验证版**：用于小范围体验与需求验证，示例数据全部为虚构。

## 快速开始

```bash
npm install
npm run dev      # 本地开发，默认 http://localhost:3000
npm run build    # 产出 dist/ 静态文件
```

要求 Node.js 20+。无需任何后端或密钥即可运行。

## 这个版本是什么 / 不是什么

- ✅ 完整业务闭环演示：客户学员、产品报名、课表签到、课时账、服务记录、成绩、财务、任务、规划、知识灵感、经营内容、设置接入
- ✅ 数据保存在浏览器 localStorage（键 `xxl-workbench-v1`），刷新保留；**换浏览器/清缓存即丢失，不跨设备同步**
- ✅ 示例学员、学校、金额、合同路径等**全部为虚构**
- ❌ 无后端、无账号体系、无真实 AI 调用（AI 功能为本地模拟草稿，验证交互流程）
- ❌ 外部接入（Supabase / Cloudflare / 企业微信 / 飞书 / 钉钉 / Notion）均未接通，状态见应用内「设置与接入」

## 已固化的核心业务规则

| 规则 | 说明 |
|---|---|
| 签到幂等 | 同一学员同一课次重复签到不重复扣课时 |
| 五状态分离 | 签到 / 服务完成 / 课时核销 / 记录归档 / 反馈交付互相独立 |
| 课时账只增不改 | 余额由流水实时复算；更正生成「补回」，退款生成「冲销」，不删历史 |
| 报名快照 | 报名时锁定价格/课时/核销规则，产品改价不影响旧报名 |
| 任务双维度 | A 到期提醒（日期规则）与 B 四象限（个人判断）分开 |
| 三口径 | 计划次数 / 已完成课次 / 已归档记录分别统计 |
| 合同三层信息 | 原件在哪里 / 工作台保存什么 / AI 可使用什么，原件不上传 |
| 金额定点 | 内部以分存储；缺考 ≠ 0 分 |
| 无指标不标爆款 | 内容模块不出现无数据支撑的爆款标记 |
| 模块隐藏 ≠ 删除 | 数据保留，随时恢复 |

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS 3 + shadcn/ui（new-york 风格）+ sonner。页面内导航为状态切换（非路由），静态托管即可运行。
