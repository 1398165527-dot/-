## 红线口径
- 合同原件不默认上传工作台；所有文档遵循「原件在哪里 / 工作台保存什么 / AI 可使用什么」三层模型。
- AI 建议不直接生效：画像更新、对外发送、发布内容均须老师人工确认；AI 不改写已确认财务与课时。
- 签到、服务完成、课时核销、记录归档、反馈交付五件事独立处理。
- 企业微信等外部权限逐项核实，不假定已开通；未知价格一律标「待报价」。
